# Detección acústica de drones en tiempo real con modelos cuantizados sobre NPU

Detecta drones por sonido: entrena varios modelos, los cuantiza a INT8 y
despliega las CNNs en la NPU Hailo-8 de una Raspberry Pi 5, comparando precisión,
velocidad y consumo en PC, CPU de la Pi y NPU.

Todos los pasos y comandos están en **[INSTRUCCIONES.md](INSTRUCCIONES.md)**.
